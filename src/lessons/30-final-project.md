# Төгсгөлийн төсөл ба цаашдын зам

Та 29 хичээлийг дуусгалаа. Одоо **өөрийн апп-ыг** бүтээх цаг боллоо.

## Төслийн санаанууд

Нэгийг сонгоод **өөрөө** хий. Хэр том байх нь хамаагүй, дуусгах нь чухал.

| Санаа | Хэрэглэх зүйлс |
|---|---|
| **Цаг агаар апп** | HTTP, JSON, FutureBuilder |
| **Зардлын тэмдэглэл** | Provider, хадгалалт, график |
| **Тэмдэглэлийн апп (Notes)** | CRUD, Navigation, хайлт |
| **Хоолны жор** | API, зураг, GridView, дуртай жагсаалт |
| **Чат** | Firebase Auth, Firestore, Stream |
| **Хөгжмийн тоглуулагч** | package, state, layout |

## Хэрхэн ажиллах вэ?

1. **1-р өдөр:** UI-н зураг (цаасан дээр эсвэл Figma) зур, хуудсуудыг жагсаа.
2. **Дараа:** Нэг нэг хуудсыг статик (өгөгдөлгүй) байдлаар хий.
3. **Дараа:** Загвар (model) бич, жишээ өгөгдлөөр холбо.
4. **Дараа:** State management, дараа нь API/Firebase.
5. **Сүүлд:** Загвар, анимаци, засвар.

> Гацвал: алдааг өөрөө 15 минут шалга → жижигрүүл (зөвхөн асуудалтай хэсгийг тусад нь авч шалга) → дараа нь л асуу.

## Цаашид юу сурах вэ?

1. **Riverpod** эсвэл **Bloc**: том апп-ын state management
2. **go_router**: нарийн navigation
3. **Анимаци:** `AnimatedContainer`, `Hero`, `AnimationController`
4. **Архитектур:** Clean Architecture, Repository pattern
5. **Тест:** unit, widget, integration
6. **Нийтлэх:** Google Play, App Store, Flutter Web deploy
7. **Платформын онцлог:** камер, GPS, мэдэгдэл
