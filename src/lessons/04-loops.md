# Давталт

Нэг ажлыг олон давтахад давталт хэрэглэнэ.

## for

```dart
void main() {
  for (int i = 1; i <= 5; i++) {
    print('Давталт $i');
  }
}
```

Гурван хэсэгтэй: `эхлэх утга; нөхцөл; алхам`.

## while

Нөхцөл үнэн байх хугацаанд давтана:

```dart
void main() {
  int n = 1;
  while (n <= 100) {
    n *= 2;
  }
  print(n); // 128
}
```

## do-while

Дор хаяж нэг удаа гүйцэтгэнэ:

```dart
void main() {
  int i = 10;
  do {
    print('i = $i');
    i++;
  } while (i < 5);
}
```

## break ба continue

```dart
void main() {
  for (int i = 1; i <= 10; i++) {
    if (i == 3) continue; // 3-г алгасна
    if (i == 7) break;    // 7 дээр зогсоно
    print(i);
  }
}
```

## Жишээ: нийлбэр

```dart
void main() {
  int sum = 0;
  for (int i = 1; i <= 10; i++) {
    sum += i;
  }
  print('1-ээс 10 хүртлэх нийлбэр: $sum'); // 55
}
```

## Даалгавар

1. 1-ээс 20 хүртэлх зөвхөн **тэгш** тоог хэвлэ.
2. Үржвэрийн хүснэгт хэвлэ: `5 x 1 = 5`, `5 x 2 = 10`, ... `5 x 10 = 50`.
3. 1-ээс 100 хүртэл 3-т хуваагддаг тоонуудын нийлбэрийг ол.
