# Flutter гэж юу вэ? Анхны програм

Flutter бол Google-ийн гаргасан UI framework. Нэг кодоор **Android, iOS, web, desktop** апп бичиж болдог. Flutter-ийн хэл нь **Dart**.

## Яагаад Dart эхэлж сурах вэ?

Flutter-ийн бүх код Dart-аар бичигдэнэ. Dart-ыг мэдэхгүй бол widget-ийн код ойлгомжгүй санагдана. Тиймээс эхний 10 хичээл Dart-д зориулагдсан.

## Орчин бэлдэх

Эхлээд суулгах шаардлагагүй. Браузер дээр ажиллуулъя: **[dartpad.dev](https://dartpad.dev)** руу ороод шинэ Dart хуудас нээ.

Дараа нь (Flutter хичээл рүү орохоосоо өмнө) [docs.flutter.dev/get-started](https://docs.flutter.dev/get-started/install) дээрээс Flutter SDK суулгана.

## Анхны програм

```dart
void main() {
  print('Сайн байна уу, Flutter!');
}
```

- `main()` нь програмын **эхлэх цэг**. Dart програм үргэлж эндээс эхэлнэ.
- `void` гэдэг нь функц юу ч буцаахгүй гэсэн үг.
- `print()` нь консол дээр текст хэвлэнэ.
- Мөр бүр `;` (цэгтэй таслал)-аар төгснө.

> Хуулж болохгүй, **өөрөө гараараа бич**. Алдаа гарвал алдааны мессежийг уншаарай.

## Даалгавар

1. DartPad дээр дээрх кодыг бичиж ажиллуул.
2. Өөрийн нэрийг хэвлэдэг хоёр `print` мөр нэм.
3. Нэг `;`-г санаатайгаар устгаад ямар алдаа гарахыг хар.
