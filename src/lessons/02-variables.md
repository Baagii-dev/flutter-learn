# Хувьсагч ба өгөгдлийн төрөл

Хувьсагч бол утга хадгалах нэртэй хайрцаг.

## Үндсэн төрлүүд

| Төрөл | Тайлбар | Жишээ |
|---|---|---|
| `int` | бүхэл тоо | `25` |
| `double` | бутархай тоо | `3.14` |
| `String` | текст | `'Болд'` |
| `bool` | үнэн/худал | `true` |

```dart
void main() {
  int age = 20;
  double height = 1.75;
  String name = 'Болд';
  bool isStudent = true;

  print(name);
  print(age);
}
```

## var, final, const

```dart
var city = 'Улаанбаатар';   // төрлийг Dart өөрөө таана
final birthYear = 2005;     // нэг л удаа онооно
const pi = 3.14159;         // compile хийх үед мэдэгдэж байх ёстой тогтмол
```

- `var`: утгыг дараа нь өөрчилж болно.
- `final`: нэг удаа оноосны дараа өөрчлөгдөхгүй. Flutter-д хамгийн их хэрэглэнэ.
- `const`: бүр эхнээс тогтмол. Flutter-д widget-ийг `const` болгож гүйцэтгэлийг сайжруулдаг.

## String interpolation

Текст дотор хувьсагч оруулахдаа `$` ашиглана:

```dart
void main() {
  String name = 'Болд';
  int age = 20;
  print('Намайг $name гэдэг, би $age настай.');
  print('Ирэх жил ${age + 1} настай болно.');
}
```

Илэрхийлэл (тооцоолол) бол `${...}`, зөвхөн нэр бол `$name`.
